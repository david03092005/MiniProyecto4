Description:

Using the OSC Controller (Open Sound Control) app and the PureData (PD) language, a DJ system was made as follows:

1. Operation of each slider, it was done in this way in order to have a simpler way of handling sounds:
  -Slider 1: This is the one in charge of managing the volume of the sounds that the system has.
  -Slider 2: This is the one in charge of managing the frequency of the system.
  -Slider 3: This is the one in charge of managing the BPM/Tempo with which the sounds that the system has will go.
  -Slider 4: This is the one in charge of whether the piano notes are played in a loose or sustained manner.

2. We use the first 3 buttons to activate a different rhythm for the Toggles, where, in a 4x4 range of Toggles by columns it has the same rhythm but with different times; and the last 2 rows change the type of sound for the Toggles corresponding to the column in which it is; And to activate them, slider 3 is used, which manages the tempos of the rhythms; the double slider is used so that the sound that is at the moment can be heard in stereo.

On the other hand, we have the Start button that starts the recording and the Stop button that ends the recording by saving it in a .wav file but at the same time when the file is playing the stop button also stops the playback, in addition, the last button called Play is used to play what was recently recorded.

3. We have the piano which is divided in such a way that each octave can be heard, for example, it was decided that in the first two rows from the DO note button to the SI note button, octaves 1, 2, 3 and 4 will be heard, in the next two rows, from the -DO note button to the -SI note button, octaves 5, 6, 7 and 8 will be heard. So each octave will be activated by means of the buttons in the last 2 rows, giving a total of 8 buttons for the 8 octaves that we have, having a total of 25 buttons in use. While the buttons from 26 to 41, each button will have a different sound to give to the piano.

Buttons 26 to 41 have been developed in conjunction with another cell phone in the same application for greater convenience when changing sounds.
